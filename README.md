Guess My Number

A simple number guessing game built using HTML, CSS, and JavaScript. The player has to guess a randomly generated number between 1 and 20 while trying to maintain the highest possible score.

Features

* Random number generation
* Guess validation
* Score tracking
* High score tracking
* "Too High" and "Too Low" hints
* Game reset using the "Again!" button
* Background color change when the correct number is guessed

Technologies Used

* HTML5
* CSS3
* JavaScript

How to Play

1. Enter a number between 1 and 20.
2. Click the **Check!** button.
3. Use the hints to adjust your next guess.
4. Try to guess the secret number before your score reaches zero.
5. Click **Again!** to start a new round.

#Project Purpose

This project was created to practice JavaScript fundamentals such as DOM manipulation, event listeners, functions, conditional statements, random number generation, and managing game state.
